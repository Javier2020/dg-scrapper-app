\# Dollar General Scraper App



Scrapes stackable coupon deals from Dollar General and displays them on a Firebase-hosted dashboard.



\## Features

\- Puppeteer-based scraper

\- Cheerio for parsing

\- Firebase Functions API

\- Firebase Hosting dashboard



\## Setup

1\. `firebase init` (enable Hosting + Functions)

2\. `npm install` in `functions/`

3\. `firebase deploy`



\## Usage

Visit `/` to view dashboard. Backend API available at `/api/coupons`.
